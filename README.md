# Juegos

Juegos educativos gratuitos para Primaria, publicados con GitHub Pages.

- [Caballeros de las Tablas](caballeros-de-las-tablas/): tablas de multiplicar del 1 al 10.
- [El Bolsillo de las Tablas](doraemon-tablas/): tablas de multiplicar del 1 al 10 con Doraemon.

Contenido de fans, gratuito y sin fines comerciales. No está afiliado a los titulares de las obras que lo inspiran.
